# Terry Gomez — Python & AI Automation Portfolio

A responsive developer portfolio featuring three runnable Python automation prototypes.

## Projects

- **Natural Language Operations AI:** Parses plain-English commands into structured proposed actions.
- **API Automation Engine:** Normalizes sample sales leads and recommends next workflow steps.
- **AI Support Automation System:** Classifies support requests and drafts review-only responses.

**Important:** These are deterministic rule-based prototypes with sample data. They do not use a live LLM, connect to real business APIs, send email, or execute actions.

## Run

Open `index.html` in a browser for the portfolio site.

Run the Python examples from the repository root:

```bash
python projects/natural-language-operations/app.py
python projects/api-automation-engine/app.py
python projects/ai-support-automation/app.py
```

## Security and publishing
